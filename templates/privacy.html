This website

This site has no accounts, sets no cookies and runs no trackers or analytics. It is a set of plain pages hosted on GitHub Pages; GitHub's own privacy statement covers the server logs GitHub keeps.

Downloads

The installer is a GitHub Release file. GitHub counts how many times it was downloaded (a number, nothing about you), and the page shows that number by asking GitHub's public API.

Questions

Contact us.

Traffic statistics

We count page views, downloads and a few actions on the pages (how far a page was scrolled, which button was pressed) to know what helps. We do it ourselves, on this server. No third-party analytics, no advertising, and no cookies for it.

  • No IP address is stored. A visitor is a hash of a random value that changes every day, the address and the browser, so we cannot follow you from one day to the next.
  • We keep the page, the site you came from (its name only), the kind of device and the browser family.
  • If your browser sends Do Not Track or Global Privacy Control, nothing is counted.
  • Statistics older than about a year are deleted.

Your account

If you make an account, we keep your name, your email, a hash of your password (never the password itself), when you signed in, and which versions you downloaded while signed in. You can delete your account at any time from its page. Your statistics are then kept only without your name.

Cookies

Two, both needed for the site to work: the session cookie when you are signed in, and a security token that protects the forms. Neither is used for tracking.

Messages

What you send through the contact form is kept so we can answer it.

Questions

Write to us.
