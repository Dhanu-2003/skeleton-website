How this website keeps you safe, and how the app protects your code.

This website

{% if site.static %}
  • Strict content policy. The pages run only this site's own scripts and styles: no inline code, no third-party scripts, nothing from other sites but the download count GitHub reports.
  • Nothing to steal. No accounts, no passwords, no cookies, no forms that store anything.
  • The download. The installer is a GitHub Release file, served by GitHub over HTTPS. Its SHA-256 is on the download page so you can check the file.
  • Transport. HTTPS only (GitHub Pages).
{% else %}
  • Strict content policy. The pages run only this site's own scripts and styles. No inline code, no third-party scripts, and no framing by other sites.
  • Passwords. Never stored. Only a slow scrypt hash with its own salt is kept.
  • Sessions. A random token in a cookie that scripts cannot read (HttpOnly, SameSite). Only its hash is in our database, and it is replaced at every sign-in. Changing your password signs you out everywhere else.
  • Forms. Every form and every write is protected against cross-site request forgery.
  • Limits. Sign-in and sign-up are rate-limited. An account locks for 15 minutes after five wrong passwords.
  • Downloads. Only the published installer is served. Its SHA-256 is on the download page so you can check the file.
  • Transport. Served over HTTPS with HSTS in production.
{% endif %}

The app

  • Secrets in tool output are masked, and keys are never written into commits.
  • Installs, flashing and pushes ask you first.
  • Your terminal stays inside your code base.
